Games Manager Elite
Allows for the management and game scoring of multiple Billiard leagues. 

a player will enter in as an administrator. a signature saying who scored the game. they will select apa or bca and define team names.
they will add each player from each team and enter who each team decides to play eachother. they will score the match accordingly and 
submit the final results. images and deeper how to details will follow. 


## Repository Branching Strategy
* **master**: Holds the shared .NET foundation (UI layout, base styles, Bootstrap/jQuery, shared models).
* **APA**: Dedicated branch for implementing APA-specific rules (Skill Levels 1-9, innings, defensive shots, and 8-ball/9-ball point tiers).
* **BCA**: Dedicated branch for implementing BCA-specific rules (10-point must system, consecutive fouls, and round-robin scoring matrices).
